# test25：设置与动态详情顶部渐变模糊

验证日期：2026-11-07。基于 test24 / 上游 PiliPlus 2.2.0.2。

## 变化

按用户提供的 Instagram 顶部参考，设置和动态详情的正文滚入顶区后，背景模糊和底色从上向下逐渐减弱，在工具栏下方 28 点内自然消失。原来的固定模糊底边不再直接截断正文。

胶囊导航、按钮和标题独立绘制，保持清晰及可点击；页面内容留白、单色设置图标和 Duo 展开竖屏的状态区并排布局沿用 test24。系统减少透明度或高对比度时使用不透明顶区。

## 验证

- 自动测试：303 项通过，覆盖真实背景的像素模糊、透明度、边缘渐隐、下方列表点击、Duo 顶栏定位、滚动状态恢复等。
- 静态分析：0 error、0 warning；保留 39 项已有 info。
- iPhone 18 Pro / iOS 27.2 模拟器：设置页浅色、深色及动态详情长文滚动截图检查。
- iPhone Duo / iOS 27.2 模拟器：通过 Device Hub 的 Open、Partially Open、Closed、Rotate Right 控件进行真实设备状态切换。设置 6 步切换保持同一列表状态和 260 点偏移；动态详情 5 步切换保持路由、页面状态、评论标签选择及 180 点正文偏移。

本轮动态详情使用本地长文测试数据验证实际页面，不代表完成登录后的线上评论业务测试。真机性能、登录、播放、投屏和画中画未在本轮重新验证。

截图及切换记录保存在本地被忽略的 `dist/test25/`。发布版本为 `2.2.0`，构建号 `25`；正式入口为 `lib/main.dart`。Release 附带 IPA、`SHA256SUMS.txt` 与 `build-info.json`，安装前需要重新签名。
