# test24：设置图标、透明顶栏与 Duo 状态保留

验证日期：2026-11-07。基于 test23 / 上游 PiliPlus 2.2.0.2。

## 界面变化

- 按用户确认采用无底块单色设置图标。UIKit 按系统 SF Symbols 绘制透明图片，Flutter 缓存后按主题着色；支持系统粗体和字号变化，旧系统缺少符号时保留单色兼容图标。
- 设置主列表和动态详情允许正文滚入顶部背景，使用透明模糊；减少透明度或高对比度时使用不透明材质。
- Duo 展开竖屏时，通用页面胶囊导航栏利用系统状态区域左侧的空白，与时间、网络、电量并排。按当前窗口的 reserved regions 定位，保留 12 点间隔，不使用设备型号或固定屏幕分辨率判断。大字号、可用宽度不足、较高工具栏及窗口坐标尚未同步时回退到普通安全区布局。
- 展开竖屏实测导航胶囊为 `(24,13)–(513,69)`，系统保留区域为 `(525,0)–(669,82)`；页面顶部占用从 152 点降至 82 点。状态栏的深浅色随页面主题更新。

## 本轮发现并修复的问题

1. 设置页在单栏与双栏切换时重建列表，导致滚动归零。现在重用同一个列表状态；设置子分类使用独立滚动存储。
2. 动态详情从 NestedScrollView 切换到双栏时丢失正文位置。现在为正文共享滚动存储标识，并为评论、转发、点赞页独立保存位置。
3. 顶栏改为覆盖正文后，跳到评论会让评论标签滑入顶栏后方。嵌套正文在接近顶栏时增加必要留白，标签停在导航下方，初始正文与标签之间不增加整条工具栏的空隙。

## 模拟器验证

使用 Xcode 27.2 / iOS 27.2 的专用 iPhone Duo，通过 Device Hub 的真实 Open、Partially Open、Closed 和 Rotate Right 控件切换。通过 Dart VM 调试服务读取路由、分类、页面/控制器身份和滚动数值，并保存各步截图。

| 场景 | 操作 | 结果 |
| --- | --- | --- |
| 首页热门分类 | 8 步展开、半折叠、合拢、旋转 | 首页、热门分类、HomeController 和 420 点滚动位置保留 |
| 设置主列表 | 9 步内外屏及横竖屏切换 | 同一列表状态及 260 点滚动位置保留 |
| 动态详情本地长文 | 8 步内外屏及横竖屏切换 | 同一路由、页面状态、评论标签选择和 180 点正文位置保留 |
| 动态详情评论定位 | 竖屏跳到评论 | 评论标签可见并停在顶栏下方 |
| 并排顶栏 | 展开竖屏与其它姿态往返 | 避开状态区域，正文与评论留白同步变化 |

动态详情使用明确标记为“本地测试内容”的长文数据，检查真实页面组件及滚动布局；该数据没有线上评论 ID，因此评论接口错误占位属于测试输入，不代表完成了登录后的动态业务验证。首页为实际匿名网络内容。

模拟器原生验证码仍采用上游 WebView 路径；真机 Release 包保留 GT3Captcha-iOS 0.15.9。真机登录、播放、投屏、画中画及性能未在本轮重新验证。
